# SuiteUI piece" (docs/factory/lead.md rules 16 and 20). One line per signature:
# `id | regex ; regex ; ... | use <SuiteUI component>`. An app View hits when its
# body (comments removed, string literals kept) matches every regex. An id
# written `file:<id>` matches the whole file instead of one view. Fields are
# split on " | " and regexes on " ; ", so a regex may hold a bare |.
