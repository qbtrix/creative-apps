# Tests/canonical-ui-concepts.txt: the UI pieces that live in SuiteUI, never
# app-local (docs/factory/lead.md rules 16 and 20). One line per concept,
# `Concept: Stem Stem ...`. A stem matches an app View struct's name (and an
# added file's name in the fast lane) at a CamelCase boundary with an optional
# plural s. The first concept that matches, in this order, wins, so put the
# narrower one first (PhotoMergeNote is BusyNote, not Notice). The concept name
# is what an `Allow-Dup-View: <concept> <reason>` PR line names.
# Read by scripts/check-dup-views; the fast lane reads main's copy.
